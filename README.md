# 🎮 Jogo da Velha Interativo

Um **Jogo da Velha moderno e interativo**, desenvolvido com **HTML, CSS e JavaScript puro**, com suporte a **Jogador vs Jogador** e **Jogador vs Computador**, **placar dinâmico**, **efeitos visuais**, **sons** e uma **interface estilizada** com foco total em **experiência do usuário (UX)**.

O jogo roda diretamente no navegador, **sem necessidade de instalação**.

## 🧠 Como Funciona

1️⃣ O jogador escolhe o modo de jogo (**PvP** ou **PvC**)  
2️⃣ O jogo inicia automaticamente com o jogador definido  

🖱️ A cada clique em uma célula:
- A célula é preenchida  
- O som de jogada é reproduzido  
- O sistema verifica vitória ou empate  

🏆 Em caso de vitória:
- As células vencedoras são destacadas  
- O placar é atualizado  
- Um som de vitória é reproduzido  

🤝 Em caso de empate:
- O jogo é encerrado com aviso visual e sonoro  

🔁 O botão **Reiniciar Jogo**:
- Limpa o tabuleiro  
- Alterna o jogador inicial
